Tennis data vocabulary: tiers, rounds, surfaces and results

What does each tennis data code mean? This page lists every closed code the API returns for tournaments, rounds, surfaces, results, rankings and charted shots, with its meaning. It is built from the OpenAPI spec, so it lists exactly the codes the API can send.

Meanings checked against the spec on 2026-11-06. Machine-readable copy: tennis-data-vocabulary.json, MIT licensed, like the spec.

How to use these codes

Every code on this page is a closed value: the API returns one of the listed codes or null, and null means the value is not known. Each code has its own link, so a schema, a README or a column note can point at one meaning. The same table is published as tennis-data-vocabulary.json for code that validates or labels the values.

Tournament tier

The level a tournament was played at in the match's own season, as the tour publishes it. A tournament keeps one id while its level changes between seasons, so the tier is read per season. Null means the level is unknown.

Tour

The tour a match belongs to. The field and the filter come from one registry, so a match selected with ?tour=X carries X. Exhibitions, team events and mixed events have no public tour name, so their tour is null.

Appears in Match.tour, GET /broadcast/live?tour=, GET /players/{playerId}/stats?level=.

Round code

The round in one controlled vocabulary, shared by live matches and the results archive. It is relative to the draw: a qualifying semi-final also reads SF, so read it together with is_qualifying. Null when the round label is not recognised.

Court surface

The court surface as stated for the event. It is never inferred from the surface a tournament used in other seasons. A Davis Cup, Billie Jean King Cup or Laver Cup match carries the surface of its own tie. The player stats filter also takes indoor, which keeps matches stated as played indoors on any surface.

Appears in Match.surface, Tournament.surface, GET /players/{playerId}/stats?surface=.

CodeMeaning
