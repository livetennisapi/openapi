Your first requestcURL / REST
curl --get \
  https://api.livetennisapi.com/api/public/v1/matches \
  --data-urlencode 'status=live' \
  --data-urlencode 'limit=5' \
  --header 'X-API-Key: YOUR_API_KEY'

Replace the placeholder with your key. A successful response may have an empty data array when no match is live. One request uses one call from your quota.
